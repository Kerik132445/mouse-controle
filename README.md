# 🖱️ Mouse Control

Небольшой проект для управления курсором Windows-компа с другого устройства (ну я тестил ток с телефона) через веб-интерфейс в одной локальной сети.

> ⚠️ **На всякий случай напишу:** программа фактически передаёт команды мыши на компьютер, где запущен сервер. Не запускайте её на чужом компьютере без явного разрешения владельца.

## ✨ Что умеет проект

- открывать веб-интерфейс управления мышью на другом устройстве;
- перемещать курсор касанием по сенсорной области;
- выполнять обычный клик;
- зажимать левую кнопку мыши для перетаскивания объектов;
- работать через локальную сеть без отдельного облачного сервера;
- запускаться как Python-скрипт или как готовый `server.exe`.

## 🧩 Как это работает

Проект состоит из двух основных частей: Python-сервера и веб-интерфейса.

```text
┌──────────────────────┐
│ Телефон / планшет    │
│                      │
│  Web-интерфейс       │
│  сенсорная область   │
└──────────┬───────────┘
           │ WebSocket
           │ команды
           ▼
┌──────────────────────┐
│ Windows-компьютер    │
│                      │
│      server.py       │
│          │           │
│          ▼           │
│       PyAutoGUI      │
│          │           │
│          ▼           │
│   системный курсор   │
└──────────────────────┘
```

### 1. Веб-интерфейс

`index.html` создаёт простую сенсорную панель, а js отслеживает события `touchstart`, `touchmove` и `touchend`.

При движении пальца вычисляется смещение:

```text
dx = новое положение X - старое положение X
dy = новое положение Y - старое положение Y
```

После этого браузер отправляет серверу сообщение вида:

```text
12,-5
```

где `12` означает движение вправо, а `-5` движение вверх.

Клик передаётся отдельной командой:

```text
click
```

Для перетаскивания используются команды:

```text
mousedown
mouseup
```

### 2. WebSocket-соединение

Браузер подключается к WebSocket-серверу на порту `8765`:

```javascript
new WebSocket(`ws://${window.location.hostname}:8765`)
```

WebSocket юзал, потому что управление курсором требует постоянного соединения и частой передачи небольших сообщений.

### 3. Python-сервер

`server.py` принимает сообщения от браузера и превращает их в действия мыши с помощью `PyAutoGUI`.

Ну для примера:

```text
click      → pyautogui.click()
mousedown  → pyautogui.mouseDown()
mouseup    → pyautogui.mouseUp()
12,-5      → pyautogui.moveRel(12, -5)
```

Сервер также запускает обычный HTTP-сервер на `8000` порту, через который отдаётся веб-интерфейс.

### 4. Дробные значения движения

Браузер может передавать дробные значения смещения, а системное перемещение мыши работает с целыми координатами. Поэтому сервер сохраняет остаток движения в `remainder_x` и `remainder_y`.

Например, если несколько раз приходит значение `0.4`, программа не теряет его полностью, а постепенно накапливает остаток до следующего целого перемещения.
(ну это вроде на винде такая фигня есть, решил тоже добавить.)

## 💻 Требования

### Для запуска готовой версии

- Windows 10/11;
- второе устройство с современным браузером;
- оба устройства должны находиться в одной локальной сети;

### Для запуска из исходников

- Python 3.10+;
- библиотеки:
  - `pyautogui`;
  - `qrcode`;
  - `websockets`.

## 🚀 Для запуск готовой версии

1. Скачайте репозиторий или готовый `server.exe`.
2. Запустите `server.exe` на **том Windows-компьютере, которым хотите управлять**.
3. При первом запуске программа определит локальный IP-адрес компьютера.
4. Будет создан QR-код со ссылкой на веб-интерфейс.
5. Откройте эту ссылку на телефоне или другом устройстве, находящемся в той же локальной сети.
6. Используйте область на экране как тачпад.

После подключения:

- короткое касание → левый клик;
- движение пальца → перемещение курсора;
- удержание → начало перетаскивания;
- отпускание → завершение перетаскивания.

## 🐍 Запуск из исходников

Клонируй репозиторий:

```bash
git clone https://github.com/Kerik132445/mouse-controle.git
cd mouse-controle
```

Установи зависимости:

```bash
pip install pyautogui qrcode websockets
```

Запусти сервер:

```bash
python server.py
```

После запуска используй адрес, который программа выводит/генерирует для локальной сети.

## 🔨 Сборка `.exe`

В проекте уже есть `server.spec`, настроенный для PyInstaller. Он включает веб-файлы `index.html` и `style.css` в сборку.

Установи PyInstaller:

```bash
pip install pyinstaller
```

А затем выполни:

```bash
pyinstaller server.spec
```

Готовый файл появится в папке `dist`.

## 🌐 Порты

Проект использует два локальных порта:

| Порт | Назначение |
|---:|---|
| `8000` | HTTP-сервер с веб-интерфейсом |
| `8765` | WebSocket-соединение для команд мыши |

Оба сервера привязаны к локальному IP компа, поэтому для работы через локальную сеть устройства должны иметь сетевое соединение между собой.

## 🔐 Безопасность

Проект является учебным и минималистичным. Он **не является полноценной системой удалённого доступа** и не предоставляет сложной аутентификации.

Не следует:

- открывать эти порты в интернет;
- настраивать проброс портов ради удалённого доступа из внешней сети;
- запускать сервер на компьютере, которым вы не имеете права управлять.

Для безопасного использования достаточно держать проект в своей локальной сети и запускать его только на доверенном компьютере.
